Typed [templ](https://templ.guide) component library for Yardrail's web UI.

```go
import ui "github.com/yardrail/ui/pkg"
```

## Usage

Serve the bundled CSS/JS:

```go
http.Handle("/static/ui/", http.StripPrefix("/static/ui/", http.FileServerFS(ui.Assets)))
```

Use components in templ templates:

```templ
import ui "github.com/yardrail/ui/pkg"

templ myPage() {
    @ui.Shell("My Page", &ui.ShellProps{}) {
        @ui.WorkflowCard("Nightly Sync", "Last run 1h ago", &ui.WorkflowCardProps{
            Status: ui.Pill("Active", &ui.PillProps{Tone: "success"}),
            Runs:   "89",
            SuccessRate: "97%",
        })
    }
}
```

## Components

### AccountMenu

AccountMenu renders an account dropdown menu with avatar, name, and email.

### ActionCard

ActionCard renders an action prompt card. Children include icon-badge, body, and action sections.

### ActionsCell

ActionsCell renders the `<td>` holding a row's buttons and RowEdit disclosures.

### ActivityRow

ActivityRow renders a run/activity entry. When Href is set it renders as a link; otherwise as a div. IsError adds the is-error modifier.

### Alert

Alert renders a banner/flash message. Children are the message content.

### AuthCard

AuthCard renders a centered auth card (login, signup, invite). Children are the card content.

### AuthorLink

AuthorLink renders an author identity: avatar, name, handle, and verified badge.

### Avatar

Avatar renders a circular initials badge. The text argument is the initials.

### Brand

Brand renders a branded logo link. Children are the logo content.

### Breadcrumb

Breadcrumb renders a breadcrumb navigation. Children are the links, separators, and current item.

### Button

Button renders a native `<button>` whose text, and accessible name, is label.

### Card

Card renders a generic container card. Children are the card content.

### Cell

Cell renders a `<td>` around its children.

### Center

Center caps its children at Measure and centres them horizontally.

### Cluster

Cluster lays its children out in a row that wraps onto further rows when it runs out of space.

### ConnectorPill

ConnectorPill renders a small connector icon badge. Children are the icon or initials.

### Content

Content renders the main content area alongside a sidebar.

### ContentMain

ContentMain renders the scrollable main content area within Content.

### CopyField

CopyField renders a code display with a copy-to-clipboard button.

### CreatePanel

CreatePanel renders a collapsible creation form panel. Children are the panel content.

### Divider

Divider renders a horizontal rule between the children of a layout primitive: an `<hr>`, or an `<li role="separator">` when the enclosing primitive renders as a list. The primitive's gap spaces it from its neighbours.

### DownloadList

DownloadList renders a list of downloadable file links. Children are the download links.

### Drawer

Drawer renders a slide-out drawer panel.

### DropdownMenu

DropdownMenu renders a dropdown menu with trigger and panel slots.

### EmptyState

EmptyState renders an empty state placeholder. Children are the message content.

### Field

Field renders a labelled `<input>` named name, with an optional hint and validation error.

### Form

Form renders a `<form novalidate>` around its children. Server-side validation reports errors through Field's Error prop, so the browser's own validation bubbles are off.

### Grid

Grid lays its children out in equal-width columns, as many as fit at MinItemWidth, so it goes from one column in a narrow container to several in a wide one.

### HitlPrompt

HitlPrompt renders a human-in-the-loop prompt card. Children are the prompt content.

### Icon

Icon returns the named Lucide icon as a templ component. The name is the icon's file stem (e.g. "pencil", "mail", "check-circle"). Panics if the icon does not exist in dist/icons/.

### IconBadge

IconBadge renders a circular icon container with the given tone. Children are the icon.

### JournalLog

JournalLog renders a scrollable container for workflow run journal entries. Children are the entries.

### ListRow

ListRow renders a settings-list row with icon, main, and actions sections.

### LiveDuration

LiveDuration renders a live HH:MM:SS counter from the given ISO 8601 start time.

### MetaRow

MetaRow renders a middot-joined row of metadata fragments.

### NavShell

NavShell renders the top navigation shell.

### Navbar

### NavbarStd

### PageAuth

### Shell

Shell renders a whole HTML document titled title, linking the library's assets from /static/ui/. Its children are the page's regions: an optional ShellTopBar, ShellNav and ShellFooter, and exactly one ShellMain.

### ShellBand

ShellBand renders an edge-to-edge band whose content keeps the page width. It must be inside a ShellMain; a ShellMain may hold any number of bands.

### ShellFooter

ShellFooter renders the page's footer as a `<footer>`. It must be a child of a Shell.

### ShellMain

ShellMain renders the page's main content as a `<main>`, the target of the skip link. It must be a child of a Shell. Its Attrs cannot set id.

### ShellNav

ShellNav renders the page's navigation as a `<nav>`, folded into a popover behind a Menu button on narrow screens. It must be a child of a Shell. Its Attrs cannot set id.

### ShellTopBar

ShellTopBar renders the page's top bar as a `<header>`. It must be a child of a Shell.

### Sidebar

Sidebar renders the main navigation sidebar.

### SidebarFooter

SidebarFooter renders the footer region of a sidebar.

### SidebarHeader

SidebarHeader renders the header region of a sidebar.

### SidebarLink

### SidebarNav

SidebarNav renders a navigation group within a sidebar.

### SidebarOrg

SidebarOrg renders an organization badge within a sidebar.

### Split

Split lays out a SplitAside and a SplitMain side by side, in the order the caller writes them, and stacks them when the main region would be narrower than half the Split.

### SplitAside

SplitAside renders the side region of a Split. It must be a direct child of a Split.

### SplitMain

SplitMain renders the main region of a Split. It must be a direct child of a Split.

### Stack

Stack lays its children out in a column with a consistent gap between them.

### Stat

Stat renders a number + label pair.

### StatusBanner

StatusBanner renders a persistent status display bar. Children are the banner content.

### Table

### Tabs

### TemplateCard

### TimelineEntries

### TimelineGroup

TimelineGroup renders a date-labeled container with a vertical time rail. Children are the group content.

### WorkflowCard
